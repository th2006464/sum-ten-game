# 凑十游戏

一个轻量的浏览器数字消除小游戏：框选一个矩形区域，区域内数字之和凑满 10 即可消除。

## 功能

- 16×10 棋盘，消除后保留空洞
- 60 秒倒计时模式（默认）、累计用时的计时模式
- 洗牌、暂停计时
- 浏览器本地保存和读取进度
- 离线优先：已访问过一次后，断网也可继续打开和游玩；对局记录会在恢复网络后自动补传
- Cloudflare D1 保存匿名对局数据（模式、分数、总智力、用时、结束时间）

## 本地运行

```bash
npx wrangler dev
```

然后打开终端显示的本地地址。Service Worker 需要通过本地服务器或 HTTPS 才能启用离线缓存。
